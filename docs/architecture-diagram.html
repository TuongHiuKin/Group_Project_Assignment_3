Luồng dữ liệu hai chiều: Request đi xuống (Browser → Presentation → BLL → DAL → SQL Server), Response đi ngược lên. Riêng AI Providers được BLL gọi trực tiếp qua HTTPS — DAL không bao giờ gọi AI. SignalR tạo kênh thứ hai: server đẩy TranscriptReady, FollowUpGenerated, GradingCompleted lên trình duyệt mà client không cần polling. Chấm điểm chạy nền: VivaGradingBackgroundService dùng Channel queue + IServiceScopeFactory để resolve scoped services cho từng job.
